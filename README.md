# Electricity Bill Generation and Management System

## Project Description
The Electricity Bill Generation and Management System is a web-based application developed to manage electricity bills easily and efficiently. It helps users generate electricity bills, manage customer details, calculate bill amounts, and track payment status.

This project uses C language for backend operations and HTML, CSS, and JavaScript for the frontend interface.

## Technologies Used
- C Language
- HTML
- CSS
- JavaScript
- Mongoose Web Server

## Features
- Generate electricity bills.
- Add and manage customer details.
- Calculate electricity bill amounts.
- View and edit customer bills.
- Track paid and unpaid bills.
- Display bill due dates.
- Apply a late payment penalty for overdue bills.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the C program using:

```bash
gcc main.c mongoose.c -o electricity_new.exe -lws2_32
```

5. Run the application:

```bash
./electricity_new.exe
```

6. Open your browser and visit:

```text
http://localhost:8001
```
